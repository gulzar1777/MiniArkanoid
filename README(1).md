# Mini Arkanoid

A small C# Windows Forms game where you move a paddle to keep a football in play.

## How to play

- Press **←** or **→** to move the paddle left or right.
- Each time the ball bounces off the paddle, you earn **1 point**.
- If you miss the ball, the game ends and a dialog shows your final score.
- Click **OK** to start a new game with **0 points**.

## Run the project

On Windows, open `MiniArkanoid.csproj` in Visual Studio 2022 with the **.NET desktop development** workload and the **.NET 8 SDK** installed. Press **F5** to play.

## Azərbaycanca

Mini Arkanoid C# və Windows Forms ilə hazırlanmış kiçik oyundur. Məqsəd paneli hərəkət etdirib futbol topunu oyunda saxlamaqdır.

### Oyun qaydaları

- Paneli sola və ya sağa aparmaq üçün **←** və **→** düymələrindən istifadə et.
- Top hər dəfə panelə dəyib geri qayıdanda **1 xal** qazanırsan.
- Topu qaçırsan, oyun bitir və açılan pəncərədə yekun xalın göstərilir.
- **OK** düyməsinə basanda yeni oyun **0 xalla** başlayır.

### Layihəni işə salmaq

Windows-da **.NET desktop development** komponenti və **.NET 8 SDK** quraşdırılmış Visual Studio 2022 ilə `MiniArkanoid.csproj` faylını aç. Oyuna başlamaq üçün **F5** düyməsinə bas.
